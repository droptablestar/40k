The stages

Same order of work as your first model, end to end, with the three prep steps — clipping, mould lines, glue — counted as one.

    Table-ready is the base coat through to the base rim. A model counts once it is painted, shaded, brought back up, detailed and based — the point where it reads clearly from arm's length, which is what table-ready means here. Varnish protects the paint rather than changing how it looks, so it is the stage after the line, not part of it.

    The percentage is weighted by miniatures, not by units — ten finished infantry move it further than one finished character. Each army carries its own percentage, and the big figure at the top is every army added together.

    Edits save on the device first and go up under your code a moment later, so the log keeps working with no signal and catches up when there is one. Anyone with your code can read and change the log, so treat it like a shared key rather than a password.
